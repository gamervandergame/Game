# Словесная Алхимия

Браузерная игра-собиралка слов на русском языке. Из 8 случайных букв нужно сложить как можно больше слов за 90 секунд.

**Играть онлайн:** https://dist-vmxinuve.devinapps.com

![Меню](https://app.devin.ai/attachments/4f38bbf4-ef63-4a69-a7f3-2a7017f537d0/menu.png)

## Механика

- **Стойка из 8 букв** генерируется по частотам русского языка.
- **Комбо ×1.0 → ×5.0** — каждое верное слово увеличивает множитель; неверное сбрасывает его до ×1.0.
- **Длинные слова дороже:** бонус ×1 / ×1.2 / ×1.5 / ×2 / ×2.5 / ×3 / ×4 за длину 3–9 букв.
- **Бонус-время** за каждое слово (1–9 сек) — длинные слова продлевают партию.
- **Особые буквы:**
  - **Золотая** — двойная стоимость очков.
  - **Кристалл** — +5 секунд за каждый кристалл в слове.
- **3 перемешивания** на партию.
- **Рекорд** хранится в `localStorage`.

### Подсчёт очков

```
очки = round( сумма_стоимостей_букв × длинный_бонус × множитель_комбо )
```

Стоимости букв (по аналогии со Скрэбблом, адаптировано для русского):
1pt: О А Е И Н Т С Р В Л
2pt: К М Д П У
3pt: Я Ы Ь Б Г
4pt: Й Ч
5pt: Х З Ж Ш Ю Э
8pt: Ц Щ Ф
10pt: Ъ

## Управление

| Действие | Мышь | Клавиатура |
| --- | --- | --- |
| Выбрать букву | клик по тайлу | буква (русская **или** латинская в раскладке ЙЦУКЕН) |
| Снять последнюю | клик по выбранному тайлу | `Backspace` |
| Очистить слово | кнопка «Стереть» | `Esc` |
| Сложить слово | кнопка «Сложить» | `Enter` |
| Перемешать стойку | кнопка «Перемешать» | `Пробел` |

## Структура проекта

```
.
├── index.html     # Разметка (меню → игра → финал)
├── style.css      # Стили: градиентный фон, тайлы, анимации
├── script.js      # Игровая логика и состояние
└── words.json     # Словарь: 7050 русских слов длиной 3–9 букв
```

Зависимостей нет — это статический сайт.

## Как запустить локально

Из-за `fetch('words.json')` файл не откроется по `file://`. Запустите локальный сервер:

```bash
# Python
python3 -m http.server 8000

# или Node
npx serve .
```

Затем откройте http://localhost:8000.

## Как редактировать

Вся настройка гейм-плея в верхней части `script.js`:

```js
const RACK_SIZE      = 8;     // букв на стойке
const START_TIME     = 90;    // стартовый таймер, сек
const COMBO_STEP     = 0.2;   // шаг комбо за слово
const COMBO_MAX      = 5.0;   // потолок комбо
const SHUFFLE_USES   = 3;     // перемешиваний на партию
const GOLD_PROB      = 0.10;  // вероятность золотой буквы
const CRYSTAL_PROB   = 0.07;  // вероятность кристалла
const CRYSTAL_TIME   = 5;     // +секунд за кристалл в слове
const GOLD_MULT      = 2;     // множитель очков золотой буквы
const VALUES         = { ... };  // стоимости букв
const POOL_WEIGHTS   = { ... };  // частоты в генераторе
const LENGTH_BONUS   = { ... };  // бонус за длину слова
const TIME_BONUS     = { ... };  // +секунд за слово по длине
```

Палитра — в `:root` блоке `style.css` (`--gold`, `--crystal`, `--rose`, …).

## Словарь

7050 уникальных русских слов длиной 3–9 букв, отфильтрованы из частотного списка [hingston/russian](https://github.com/hingston/russian) (Лидсский корпус). Буква `ё` нормализована в `е` и при загрузке, и при сравнении.

Чтобы добавить/убрать слова — просто отредактируйте JSON-массив в `words.json`.
